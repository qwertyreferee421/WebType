# WebType
A web plugin that has iframing and fetches assets from websites, integratable.
---
This was inspired by the embedding content of Macromedia and Adobe Flash, using iframes.
---
This was originally made for an animation software project me and another person made, but then was repurposed months later.

WebType has two versions: Developer and WebType (normal user plugin). Developer is built for developers developing in WebType and needs to be built in to every project that uses WebType. WebType is a web plugin that directly communicates with Developer to embed sites and show content from other user selected sites.
